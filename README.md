# Responsive Personal Portfolio

A simple responsive personal portfolio website created for an HTML, CSS and JavaScript assignment.

## Features
- Semantic HTML5 structure
- CSS selectors, properties and responsive styling
- Flexbox and CSS Grid layouts
- Mobile navigation menu
- Light/dark theme toggle
- Interactive contact form
- Responsive project and skills sections
- Works on desktop, tablet and mobile screens

## Run
No installation is required. Open `index.html` in a browser.

## GitHub
Create a repository such as `responsive-personal-portfolio`, upload these files, and use the repository URL as the assignment submission link.
