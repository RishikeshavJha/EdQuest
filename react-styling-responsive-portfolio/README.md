# React Styling & Responsive Portfolio

A small React portfolio application created for the styling assignment.

## Assignment coverage

### 1. UI/UX
The design uses clear hierarchy, readable typography, accessible labels, consistent spacing, hover feedback and a mobile-friendly layout.

### 2. Inline styles
`Header.jsx` receives `themeButtonStyle` from `App.jsx` and applies it through the JSX `style` attribute.

### 3. Styled Components
The project uses `styled-components` for the page shell, navigation, hero, cards, sections and contact form.

### 4. CSS-in-JS with Emotion
`App.jsx` uses Emotion's `css` helper to style the skill chips.

### 5. Flexbox
The navigation, skill list and several component layouts use Flexbox.

### 6. CSS Grid
The hero, project cards, about section and contact form use CSS Grid.

### 7. Media queries
Responsive breakpoints adapt the hero, project cards, about section, navigation and contact form for smaller screens.
